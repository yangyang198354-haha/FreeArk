粘性定位在页面顶部。半透明深色背景 + backdrop-filter 毛玻璃效果。底部有一条霓虹渐变动画线。

布局要点
Header 采用三列布局：左区 88px（返回按钮）、中间 flex:1（标题居中）、右区 88px（胶囊按钮组）。
标题使用 .cyber-font-display + font-size: 18px + letter-spacing: var(--cyber-tracking-wider)。
顶部需预留 44px 状态栏高度 (h-11)。

系统故障
结露预警
SVG 圆环结构说明 /* * 仪表 SVG 结构 (viewBox="0 0 100 100")： * * 层级1 - 外圈静态底环: * * * 层级2 - 外圈填充环 (动画): * * * 层级3 - 中圈静态底环: * * * 层级4 - 中圈填充环 (脉冲): * * * 层级5 - 内圈静态底环: * * * 层级6 - 中心数值: * 数值 * * 层级7 - 十字准线: * * */
CSS - 仪表动画 @keyframes ringDraw { from { stroke-dashoffset: 276.46; } to { stroke-dashoffset: 0; } } @keyframes ringPulse { 0%, 100% { opacity: 1; filter: drop-shadow(0 0 4px currentColor); } 50% { opacity: 0.5; filter: drop-shadow(0 0 12px currentColor); } } /* 威胁闪烁叠加 */ @keyframes warningFlash { 0%, 100% { opacity: 0; } 50% { opacity: 0.6; } } /* threat-border: 边框渐变流光 */ .threat-border::before { content: ''; position: absolute; inset: -1px; border-radius: inherit; padding: 1px; background: linear-gradient(90deg, var(--cyber-neon-magenta), var(--cyber-neon-orange), var(--cyber-neon-yellow), var(--cyber-neon-magenta)); background-size: 300% 100%; animation: borderTrail 3s linear infinite; -webkit-mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0); -webkit-mask-composite: xor; mask-composite: exclude; }
圆环周长计算
circumference = 2 * PI * radius
r=44: 276.46 | r=38: 238.76 | r=34: 213.63
stroke-dashoffset 控制填充比例：0 = 100% 填充，276.46 = 0% 填充。

重要
4 角变体需要两个子元素 <span class="br-tr"></span> 和 <span class="br-bl"></span>，因为 CSS 伪元素只有 ::before 和 ::after 两个。颜色通过 --corner-color 自定义属性控制。
